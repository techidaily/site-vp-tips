## \[Tutorial\] How to Use AMD Built-in Video Converter (ATI Avivo Video Converter)

**Where to get the video transcoding freeware from AMD** 

[ATI Avivo Video Converter](https://en.wikipedia.org/wiki/ATI%5FAvivo) can be found quickly for some users. Right-click on the desktop and select AMD Catalyst Control Center at the top. On the left pane, click Video and select AMD Video Converter from the drop-down menu. You should see Start Video Converter button on the right side now. 

![Get AMD Video converter freeware](https://www.macxdvd.com/mac-video-converter-pro/article-image/amd-catalyst-control-center.jpg) 

Get AMD Video converter freeware

**What to do if AMD Video Converter is missing?**

Many of us are annoyed with the issue of AMD GPU accelerated video converter or "Start Video Converter" option not showing up after the driver update. Things become a bit more complicated then. You need to download codec package to solve the issue. Following steps below:

**1.** Go to AMD official site to download AMD Media Codec Package (for Windows 8/Windows 10) or ATI Avivo Codec Package 10.12 or Windows 7 or earlier. The codec package contains AMD video transcoder and codecs for [GPU accelerated video transcoding](https://tools.techidaily.com/macxdvd/products/) and the package is no longer offered by AMD. 

**2.** Follow on-screen instrument and install the codec, then restart PC. 

![AMD video converter](https://www.macxdvd.com/mac-video-converter-pro/article-image/amd-video-converter-1.jpg) 

AMD video converter

**Start to Convert Video with AMD GPU acceleration**

**1.** Click Start Video Converter under the Video menu on the AMD VISION Engine Control Center, and a window will display. 

**2.** Click Select Source and select a video to process. Then click Browse to change the default output folder, and click Next. Batch processing is not supported by the video converter freeware powered by AMD. 

**Tips** \- ATI Avivo Video Converter supported formats: H.264, VC-1, WMV9, WMV9 PMC, MPEG-2, MPEG-4, DivX, and some iPod and PSP formats.

**3.** Click the drop-down icon under Output Video format section and select a format you prefer. You can also adjust the output quality. The input file and output file info is shown below the Output Quality section, which consists of file size and bitrate. 

**4.** Click Next to begin the AMD hardware based video conversion process.

The AMD built-in video converter is not a professional tool for video transcoding. Supported format is very limited, many users are crying that input files are not recognized, MKV doesn't work, HEVC get stuttered, etc. You may need a better and [faster GPU accelerated video converter](https://tools.techidaily.com/macxdvd/products/) that provides AMD acceleration.
